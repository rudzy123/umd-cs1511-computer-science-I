# Learning log — Day 1

Use this page after you build the project, run the tests, and walk through one demonstration session. Write a few concrete sentences under each prompt. Name the function, input, or error message you mean.

## What I remembered quickly

Which declarations, loops, or function calls felt automatic? Point at one place in `src/` or `include/` that you could explain to someone else without looking it up.

## What I had forgotten

Which rule surprised you when a test failed or a warning appeared? Examples worth checking: integer division, `const`, zero-based indexes, and what an empty collection should do.

## Which bug took the longest to resolve

What did the failing test or compiler diagnostic actually say? What was the incorrect assumption underneath it?

## Where I used decomposition

Where did you split work into a separate function instead of growing `main`? Which module owns the rule, and which code only prints it?

## What I would improve in a second iteration

Which contract, name, or test would you change after reading the complexity table in the README? Would you still handle that edge case in the same function?
